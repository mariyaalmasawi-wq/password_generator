🔐 Password Generator
A simple Python script that creates a random password based on how many letters, numbers, and symbols the user wants.
-----------------------------------------
🚀 Features
Choose how many letters, numbers, and symbols to include

Generates a fully randomized password

Uses Python’s random and string modules

Validates input to avoid mistakes
-----------------------------------------
▶️ How to Run
Make sure Python is installed

Run the script: python password_generator.py
-----------------------------------------
